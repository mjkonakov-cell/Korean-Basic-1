한글 그림 · 단어 짝 맞추기 게임 (168 단어)
===================================================

사용법:
1. HangulMatchingGame.html 파일을 더블클릭하면 브라우저에서 바로 실행됩니다.
2. 화면에서 기본 자음 14개 중 하나를 선택하세요.
3. 그림과 한글 단어를 하나씩 클릭해 맞추세요.
4. 4쌍, 6쌍, 12쌍의 난이도를 선택할 수 있습니다.
5. 학습 기록은 해당 컴퓨터/브라우저에만 저장됩니다.
6. "발음 듣기"는 기기에 설치된 한국어 음성을 사용합니다.

학부모에게 웹 링크로 공유하는 방법 (기존 GitHub Pages 사이트 사용):
1. GitHub에서 공개 강의 사이트 저장소(Korean-Basic-1)를 엽니다.
2. Add file > Upload files 를 클릭합니다.
3. HangulMatchingGame.html 파일을 저장소 최상위 폴더에 업로드하고 Commit changes 를 누릅니다.
4. 기존 GitHub Pages 사이트가 활성화되어 있다면, 몇 분 후 저장소 루트 파일 이름으로 공개됩니다.
5. 브라우저에서 공개 페이지가 정상 작동하는지 먼저 확인한 다음 그 실제 주소를 학부모에게 전송하세요.

주의: GitHub에 업로드 전에는 공유 가능한 공개 웹 링크가 생성되지 않습니다.
이 단일 HTML 파일에는 모든 그림과 단어가 내장되어 있어 별도의 사진 파일 업로드가 필요 없습니다.
